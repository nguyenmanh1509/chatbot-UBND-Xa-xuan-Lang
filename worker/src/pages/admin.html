Gửi tin trong cửa sổ 24h sau khi người dùng nhắn là miễn phí. Không cần mua gói nào.

📖 Hướng dẫn đầy đủ 7 bước (mở ra khi cần)

Chưa biết lấy ở đâu? Xem file hướng dẫn chi tiết trong thư mục worker/docs/facebook-setup.md — có mô tả từng màn hình, kèm bảng lỗi thường gặp.

  1. Tạo app — Vào developers.facebook.com/apps → Create app → chọn loại Business → điền tên (vd "UBND Xuân Lãng Chatbot") → chọn Business account của UBND → Create app.
  2. Thêm sản phẩm Messenger — Trong app, bấm Add product → tìm Messenger → Set up. Ở màn hình này sẽ thấy Page ID ở khung bên phải (chọn Page của UBND ở dropdown).
  3. Lấy App Secret — Menu trái: App settings → Basic → mục App secret → bấm Show → copy.
  4. Tạo Page Access Token — Menu trái: Messenger → Settings → phần Access Token → bấm Generate token → chọn đúng Page → Next → chọn quyền: pages_messaging, pages_show_list, pages_manage_metadata → Next → Done → copy token bắt đầu bằng EAA....
    ⚠️ Token này có hạn. Nếu hết hạn, quay lại đây bấm Generate token lại rồi lưu lại vào Admin.
  5. Điền 4 trường ở trên — điền vào Admin panel rồi bấm Lưu cấu hình. Đặt Verify Token là chuỗi tự chọn, ví dụ xuanlang_verify_2026.
  6. Đăng ký Webhook — Menu trái: Messenger → Settings → mục Webhooks → bấm Edit (hoặc Add).
    • Callback URL: dán URL ở mục "Webhook callback URL" phía trên (bấm vào để copy).
    • Verify Token: dán đúng chuỗi bạn vừa đặt ở bước 5.
    • Bấm Verify and Save → Meta gọi URL của bạn, nếu đúng sẽ hiện "Success".
    • Subscribe fields: tick messages → Subscribe.
  7. Bật kênh & kiểm thử — Tick ô Bật kênh Facebook → Lưu cấu hình → bấm Kiểm tra kết nối (phải báo "Đã kết nối tới Page: …").
    Sau đó mở trang Facebook của UBND, bấm nút Messenger → gõ hộ khẩu hoặc kết hôn → bot phải trả lời.

Lưu ý: Webhook của Meta chỉ nhận được sau khi Page ở trạng thái Published (Settings → General → Publish Page), và trong giai đoạn phát triển bạn có thể chỉ cần Page do chính bạn quản lý.
